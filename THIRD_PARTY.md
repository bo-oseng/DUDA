# Upstream components

This project incorporates and uses components from:

- OneRestore: https://github.com/gy65896/OneRestore (restoration architecture).
- DINO: https://github.com/facebookresearch/dino (vision-transformer and feature utilities; source headers retained).
- DINOv3: https://github.com/facebookresearch/dinov3 (pretrained feature backbone).
- PEFT: https://github.com/huggingface/peft (BOFT adapters).
- PyIQA: https://github.com/chaofengc/IQA-PyTorch (MUSIQ, CLIP-IQA, LIQE and Q-Align interfaces).
- NumPyro, JAX, scikit-learn and Continuum (Gaussian fitting and incremental data handling).

Existing copyright and license notices in source files are retained. This extraction does not assign a new license to upstream code, datasets or model weights. Their respective terms continue to apply.
